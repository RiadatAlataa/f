# دليل اختبار الاتصال الحقيقي بحاوية Cloudflare R2
## جمعية ريادة العطاء لخدمة الإنسان بالعسيلة

تم إعداد هذا السكربت لإجراء اختبار حي وآمن تماماً بين خادم الجمعية وحاوية **Cloudflare R2** دون كشف أي مفاتيح سرية ودون لمس أي ملفات حقيقية للمستفيدين أو المتطوعين.

---

### الضوابط الأمنية المطبقة في السكربت:
1. **عدم كشف المفاتيح:** لا يقوم السكربت بطباعة أو تسجيل أو تخزين المفاتيح، بل يكتفي بالتحقق من وجودها وطولها المرمز.
2. **العزل التام:** جميع عمليات الرفع تتم حصرياً داخل المجلد المنعزل `test-uploads/`.
3. **حماية مسارات المستفيدين:** حظر برمجي صارم يمنع التعامل مع أي مسار خارج `test-uploads/`.
4. **فحص التكامل:** فحص تطابق بصمة التشفير `SHA-256` للملف بعد استرجاعه للتأكد من وصوله سليماً 100%.
5. **التنظيف الآمن:** يتم حذف ملف الاختبار الوهمي فوراً والتحقق من اختفائه عبر استجابة `404 Not Found`.

---

### طريقة التشغيل على نظام Windows عبر PowerShell:

افتح موجه أوامر **PowerShell** ونفّذ الأوامر التالية بالترتيب:

#### 1. الانتقال لمجلد المشروع:
```powershell
cd C:\path\to\project
```

#### 2. تعيين مفاتيح الاتصال كمتغيرات بيئة مؤقتة للجلسة الحالية:
*(استبدل القيم الافتراضية ببيانات R2 الحقيقية الخاصة بالجمعية)*
```powershell
$env:R2_ACCOUNT_ID = "ضع_معرف_الحساب_هنا"
$env:R2_ACCESS_KEY_ID = "ضع_معرف_المفتاح_هنا"
$env:R2_SECRET_ACCESS_KEY = "ضع_المفتاح_السري_هنا"
$env:R2_BUCKET_NAME = "اسم_الحاوية_الخاصة_بالجمعية"
```

#### 3. تشغيل فحص الاتصال:
```powershell
node scripts/test_real_r2_connection.mjs
```

#### 4. مسح المفاتيح من ذاكرة الجلسة بعد انتهاء الفحص (للأمان التام):
```powershell
Remove-Item Env:\R2_ACCOUNT_ID
Remove-Item Env:\R2_ACCESS_KEY_ID
Remove-Item Env:\R2_SECRET_ACCESS_KEY
Remove-Item Env:\R2_BUCKET_NAME
```

---

### مخرجات الاختبار المتوقعة:
عند نجاح الفحص ستظهر شاشة مشابهة لما يلي:
- `[PASS] متغيرات البيئة مكتملة وصالحة`
- `[PASS] تم الاتصال بالحاوية بنجاح`
- `[PASS] تم رفع الملف التجريبي بنجاح (test-uploads/probe_...)`
- `[PASS] تم استرجاع الملف بنجاح وبصمة التشفير متطابقة 100% (SHA-256)`
- `[PASS] تم إرسال أمر حذف الملف التجريبي`
- `[PASS] تم تأكيد إزالة الملف تماماً من الحاوية (404 Not Found)`
- `النتيجة العامة: PASS`
